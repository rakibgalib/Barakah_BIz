Core Services Overview

Identity Service

  • Authentication: Email/Password, Social Login (OAuth 2.0), Biometric (Mobile), 2FA (TOTP/SMS), SSO (SAML/OIDC)
  • Authorization: RBAC (Roles/Permissions), ABAC (Attribute-Based), Tenant Isolation, Fine-Grained Access Control
  • Security: JWT with Refresh Tokens, Password Hashing (bcrypt), Rate Limiting, Brute Force Protection
  • Audit Logging, AI-Powered Anomaly Detection, Risk Scoring

Tenant Service

  • Multi-Tenant Management: Create and manage tenants
  • Subscription Management: Tier-based plans (Basic, Professional, Enterprise, Pharmacy, Restaurant, Clothing, SuperShop — pricing TBD)
  • Customization: Per-tenant branding and settings, resource isolation (dedicated schemas), feature flags, usage analytics

Catalog Service

  • Product Management (CRUD), Category Management (hierarchical), Inventory Tracking, Full-text search with relevance, Bulk Import/Export, Version Control, Multi-Format Support

Order Service

  • Order Processing (create, update, track), Inventory Integration (auto stock deduction), Payment Integration, Order Status Tracking, Return Management, Analytics

Inventory Service

  • Real-Time Stock Tracking (multi-location), Low-Stock Alerts, Automatic Reordering Rules, Stock Reservations (checkout holds), Warehouse/Branch Transfers, Batch & Expiry Tracking

Payment Service

  • Payment Processing (Stripe integration), Multiple Payment Methods (card, mobile wallet, cash), Refunds & Partial Refunds, Payment Reconciliation, Fraud Detection Hooks, PCI-DSS Scoped Handling

Notification Service

  • Multi-Channel Delivery (Email, SMS, Push), Templated Messages, Event-Driven Triggers (via Kafka), Delivery Status Tracking, User Notification Preferences

Analytics Service

  • Business Intelligence Dashboards, Sales & Revenue Reporting, Customer Behavior Analytics, Cross-Tenant Aggregation (anonymized), Data Export (CSV/PDF)

AI Service

  • Central orchestration layer for Gemini/DeepSeek/Claude integrations — see the AI Technology Stack section for details. Scheduled for the AI Integration phase of the roadmap (Month 7-8).

Database Design Overview

Assumption: Citus is adopted from day one for future scale. If early tenant volume doesn't require sharding, a single PostgreSQL instance with the same schema strategy can defer this cost until it's actually needed.

Citus Distributed Database

  • Primary Node: metadata and coordination
  • Worker Nodes: distributed data storage
  • Shared Tables: Tenant, User, Role (Replicated)
  • Distributed Tables: Products, Orders, Inventory

Schema Strategy

  • Public Schema: Tenants, Users, Roles, Permissions
  • Tenant Schema (Dynamic): tenant_{tenant_id} with Products, Categories, Orders, Inventory, Customers, Employees
TablePurposeDistribution
TenantsBusiness tenantsReference
UsersSystem usersReference
ProductsProduct catalogDistributed
OrdersOrder managementDistributed
InventoryStock levelsDistributed
CustomersCustomer dataDistributed

Index Strategy

  • B-tree: Primary keys, foreign keys (all tables)
  • GIN: Full-text search (Products, Orders)
  • JSONB: Dynamic attributes (Products, Customers)
  • Spatial: Location-based (Branches)

Security & Compliance

Security Features

  • Authentication & Authorization: MFA (TOTP, SMS), RBAC, JWT tokens, session management, strong password policy
  • Data Protection: Encryption at rest (database), encryption in transit (TLS 1.3), PII masking, anonymization (GDPR), secure storage (Key Vault)
  • Security Monitoring: Real-time alerts, complete audit trail, vulnerability scanning, annual penetration testing, DDoS protection

Compliance Requirements

  • Regulatory: GDPR, PDPL, HIPAA (healthcare), PCI-DSS (payment), ISO 27001
  • Audit: Complete audit trails, access logs, change management, data retention, compliance reporting

Monitoring & Observability

Monitoring Stack

  • Infrastructure: Prometheus (metrics), Grafana (visualization), ELK Stack (logging), Jaeger (tracing), AlertManager
  • Application: Health checks (/health), performance metrics, business metrics (orders, revenue), error tracking (Sentry/App Insights), user analytics
  • AI Monitoring: Model performance (accuracy, latency), API usage (token consumption), cost tracking, quality metrics, feedback loop
